# iOS 3.5.1 Build 2

以 iPhone 原生体验为目标，最低 iOS 17，使用 iOS 26 SDK 编译。

- 原生 Liquid Glass：浮动导航、快捷操作、聊天输入框、笔记 AI 控制；系统工具栏、菜单和弹窗由新 SDK 自适配。减少透明度开启时回退为高对比实体表面。
- 个人头像：恢复小猫、小熊、狐狸、猫头鹰预设；PhotosPicker 只读取用户主动选择的照片，缩略、居中裁切后写入加密设置。顶部头像与设置页同步。
- AI 形象：统一蓝白云雾圆球，Canvas 按显示尺寸绘制，处理时连续变化；气泡、笔记与语音共用边缘动效。空闲停止逐帧刷新，遵循减少动态效果设置。
- 键盘：移除隐藏 TabView 的重复布局，输入框使用底部安全区域。键盘出现时隐藏主导航，保留消息输入和发送按钮。
- 卡包：卡面自适应比例，装饰只做 overlay，不参与高度测量；尾号和卡组织标识始终在卡面内部。自定义 Layout 保留所有折叠卡片可见条带，可滚动到最后一张。
- 笔记：列表生成可读 Markdown 摘要，保留原文；AI 预览排版，依据独立折叠展示，不再重复写进正文。编辑关闭前确认，草稿加密。
- 对话：历史保留模式信息，继续对话恢复对应模式；新对话取消旧生成任务，聊天草稿在页面切换时保留，锁定时清空。
- 移除用户界面中的迁移和工具链介绍。

验证包括核心测试、iOS 18 与 iOS 26 模拟器 UI 回归和加密测试、真实 arm64 IPA 构建。实际通过状态以交付验证记录为准。开发环境没有已连接的真实 iPhone，不把模拟器结果当作真机验证。
