# 个人助理 3.5.1 · Build 16

群聊改成直接自然聊天：移除输入框上方的 @ 选择器。可以直接叫名字、引用某条消息，或按上下文接话。明确称呼、引用和集体问候就地判断；指代与间接提及等不明确消息使用一次简短的 Flash 发言判断，结果校验并保存后再让对应伙伴接话，每轮每人至多一条，支持取消和只重试未完成的成员。

修复“群发言者：female”“群成员「大肥鱼」（female）说”等程序标记反复叠进正文的问题。发言身份与正文分开传递，保持真实消息顺序；旧记录、引用、历史窗口和新回复的预览/最终正文均清理已知旧标记，原始聊天与引用快照保留。只返回身份标签的无效候选不会保存为回复。

两位伙伴继续使用各自身份、形象与表情包，群内仅使用共享聊天、记忆和相处习惯，私聊不自动进入群聊。群聊摘要保留发言者归属。沿用 Build 15 的流式显示。

验证状态：发布前必须通过同源核心、资源、iOS 单元、群聊页面与既有伙伴页面检查；最终数量与结果在校验完成后补充。测试中的模型响应为网络模拟数据，不代表已进行真实付费模型的连续对话质量或速度评测。指代判断仍由模型执行，可能需要用户自然澄清。

安装：使用原签名身份与相同 Bundle ID 覆盖安装 Build 13/14/15，保留四位 PIN 和现有资料，无需卸载。iPhone arm64 未签名 IPA，最低 iOS 17，iOS 26 SDK。
