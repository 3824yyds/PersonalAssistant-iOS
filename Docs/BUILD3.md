# iOS 3.5.1 Build 3

- 四种个人头像分别用绘图工具重画。新素材是居中、完整背景的方形图，预览、列表和顶部入口共用正圆裁切；不再使用原素材的偏斜椭圆边缘。以 512px JPEG 编入资源，高清绘图原稿不内置安装包。
- 外观偏好作为设备设置立即保存，直接更新 UIWindow 的界面样式，使已呈现的设置页、菜单和主页面同步切换。不等待加密资料写入，不重建页面或清空正在编辑的内容。首次解锁会读取旧资料中的偏好；锁屏插画保持浅色可读性。
- 登录控件移入插画中央留白区域，统一宽度、对齐与间距；密码键盘出现时让出空间。Face ID 保留单一圆形图标入口和无障碍名称。
- 导航栏保留原生玻璃外壳，增加选中项胶囊与连续滑动高亮，保持四个栏目和现有快捷入口。展开时保留页面压暗，将底层颜色与页面统一并约束导航内容的绘制边界，避免浮动栏后方露出矩形白底。快捷操作与加号保持同一中心线。
- AI 处理改为统一的柔和多色流光，限制在气泡与处理控件的圆角内，移除旋转硬边描线。笔记、财务分析、聊天共用配色与动效；不显示虚假的完成百分比；取消后停止刷新，尊重减少动态效果设置。

视觉参考：用户提供的 iOS 导航截图；[Google Design 的 Gemini 视觉系统](https://design.google/library/gemini-ai-visual-design)与 [Gemini 新设计介绍](https://blog.google/innovation-and-ai/products/gemini-app/next-evolution-gemini-app/)。借鉴渐变、柔和形状和连续动效，不使用 Gemini 品牌标识或暗示模型来自 Google。
