# 个人助理 3.5.1 · Build 17

伙伴聊天新增自然语音消息。进入私聊或群聊，打开右上角「… → 语音回复」，可选择文字、语音或语音和文字，分别设置女生/男生的固定声音、0.8至1.2倍播放语速和是否自动播放。默认音色为芊悦Cherry与晨煦Ethan。沿用原有DeepSeek聊天、记忆、表情和群聊接话方式。

本版接入阿里云百炼北京地域qwen3-tts-flash官方接口。**需要用户自己的百炼语音服务账号和API Key，安装包不含共享密钥。官方免费演示不提供本App的持续生成接口；没有账号时保留文字，语音设置提供开通与免费额度说明。免费额度有条件和有效期，不承诺长期免费或真人不可区分。** 密钥保存在本机钥匙串，不使用DeepSeek密钥代替，也不放入资料库或导出备份。

文字生成与语音生成分开，语音不会阻塞下一条文字回复。语音模式额外提示伙伴使用简短自然口语，仍保存完整正文；超过语音长度上限明确提示查看文字，不截断成不完整录音。可展开文字、停止播放和重试语音；额度不足、网络失败、取消生成不会丢失文字、重复发送用户消息或伪造发送成功。不使用系统朗读或固定演示音频充当自然语音。

群聊根据每条消息的真实发言者使用对应音色，合成队列和自动播放顺序执行，避免同时出声。自动播放默认关闭；离开页面、锁定、进入后台或音频中断时停止生成与播放，移除耳机也停止。已有文字消息可长按选择「语音播放」。

仅将这一条回复的朗读文本发送给语音服务，不发送整段历史、记忆或账本。去除Markdown装饰、引用序号、网址和不适合朗读的emoji。下载完整音频后验证可播放，再加密缓存；音频下载不携带API Key，拒绝重定向与非官方音频地址。本机语音缓存独立于32MB加密资料库，有64MB/100条上限，可单独清理。恢复备份后保留聊天文字，缺失的缓存需重新生成。换音色后重新生成会产生新用量，调整播放语速无需重新合成。
