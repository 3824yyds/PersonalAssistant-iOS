# 只有 iPhone 时的签名与安装

1. 获取交付的 `PersonalAssistant-iOS-3.5.1-build7-unsigned.ipa`，源码 ZIP 不能当作安装包。
2. 在你已经使用的 iOS 签名工具中导入 IPA，选择你自己的有效签名证书及对应描述文件，然后签名安装。不同工具具体界面不同，以其说明为准。
3. 如系统要求，在“设置 → 通用 → VPN与设备管理”中完成相应信任。开发者签名方式可能还需要在“设置 → 隐私与安全性”开启开发者模式；是否出现取决于签名/安装方式。
4. 初次启动创建资料库密码；已经使用本应用时请保留相同应用标识和签名进行更新，更新前导出加密备份。
5. 在“个人详情 → 云端智能”保存自己的 DeepSeek Key，刷新模型列表。密钥只保存在本机钥匙串中。
6. 可在“本机智能”下载约1.12GB模型，或导入对应的完整 GGUF。录音和拍照首次使用会申请系统权限。

## 从 GitHub 构建获取 IPA

在手机浏览器打开本工程仓库，进入 Actions。已成功的 `iOS build and unsigned IPA` 运行中下载 `PersonalAssistant-iOS-3.5.1-build7-unsigned` artifact；它是ZIP包装，解压后才是IPA。下载需要登录你自己的GitHub账号。

在 Actions 页面选择 `Run workflow` 手动启动。普通提交不会自动启动完整打包。流程先在 Ubuntu 运行核心测试，在 macOS 运行 iOS 18 / 26 模拟器测试，再构建 Metal 原生库及真正的 iOS arm64 程序。生成时不上传你的证书，不使用Apple ID，也不提交App Store。

## 注意

- 未签名IPA本身不能直接安装；更改扩展名不能代替签名。
- 不同证书、BundleID或工具可能把更新视为另一个应用；更新前导出加密备份。
- 证书过期或撤销可能导致应用打不开，请用自己的签名方式重新签名，不要先删除未备份资料。
- 本项目没有后门下载证书、共享他人证书或绕过iOS权限的逻辑。
