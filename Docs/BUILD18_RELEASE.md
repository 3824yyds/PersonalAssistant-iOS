# 个人助理 3.5.1 · Build 18

修复伙伴把旧聊天当作今天、无法识别引用消息日期，以及把取名时间当成出生日期的问题。私聊请求提供每条消息的真实发送时间与设备时区，群记录也保留时间；引用消息从原始记录核对日期，不使用引用发生的时间替代。当前用户消息沿用已保存的原ID与日期，不临时生成新时间。补上日期询问与改名操作的区分，即使不加问号，“我给你取名是什么时候”也不会把名字改成“是什么时候”；引号中的新名字仍可正常设置。

新增当前聊天的只读历史检索：需要时查询本机保留的旧窗口，返回按实际日期排序的原文片段和日历天数。不读取另一位伙伴的私聊，不修改原记录。检索在本机执行，不查询公开网页；模型按需读取结果会增加工具往返与相应用量。每轮最多两次、每次最多八条有长度上限的结果；找不到时说明现存记录不足，不声称从未发生。只向模型发送实际检索出的必要片段，禁止把私聊检索片段直接复制到网页搜索词。

压缩请求和最终摘要保留原消息日期与引用原消息日期；旧摘要不按本次压缩时间重新标记事件日期。历史相对时间以原消息时间为参照，取名日期不作为年龄或生日的依据。日历天数按设备时区计算，跨午夜不等于满24小时。

没有新增生日/年龄资料，不编造设定；基于真实时间证据回答，语义判断仍由模型完成，不保证任何自然语言问题都不会误解。界面的48,000字符预算仍是聊天正文预算，不是模型token总量，时间元数据与系统提示另有开销。原始消息、既有名字、四位PIN和资料库格式保留。
