个人助理 3.5.1（Build 13）

- 表情入口改为输入框下方展开的底部面板，和键盘互相切换；聊天与草稿仍留在当前页。点图直接发送，面板可继续浏览。
- “我的”表情支持从相册选择照片、填写名称与含义、决定是否允许伙伴使用。图片缩小至最长512像素、单张256KB内，保留透明PNG并重新编码去掉原照片元数据；只存本机加密资料，不把照片像素发给DeepSeek。对话提供名称与含义帮助理解和选择。
- 自定义图片上限32张（含历史聊天保留的图片）。长按表情可移除或切换她的使用权限；已发过的图片保留在原聊天，未使用的图片可释放。整体资料库仍受原32MB上限约束，保存失败会保留编辑内容。
- 消息长按“回复”可指定某条用户/伙伴消息。输入区显示可取消的引用预览；发送后保存引用快照，文字、表情均可带引用。引用内容进入模型上下文、用量光圈及精简，明确区分原发言者；取消保留草稿，失败重试保留原引用。引用不会自动执行旧消息里的取名或记忆指令。
- 新增四张逐张绘制的恶搞表情：绷不住了、吃瓜、我裂开了、就这？。风格更夸张，合计十张内置表情；沿用语境、频率及温柔模式限制。
- 顶部头像加入轻呼吸和晃动、思考提示；回复使用内置表情时可切换相应静态神态。不增加额外模型请求；尊重系统“减少动态效果”、后台暂停，并可在她的资料关闭头像动效。这是轻量UI动效，不是Live2D或面部绑定。
- 资料库统一改为4位ASCII数字PIN，支持前导零。创建、解锁和备份验证均只接受四位数字，采用新版本加密封装，保留PBKDF2/AES-GCM及错误尝试冷却。旧12位/长密码资料和备份不兼容。全新安装时不会继承旧钥匙串中的失败次数及生物解锁密钥。

**本次按用户要求先卸载旧版，再安装并新建4位PIN资料库，不提供旧密码迁移。旧版资料和旧备份不能在本版解锁。** 仍为未签名iPhone arm64，最低iOS17，iOS26 SDK，Bundle ID cn.local.assistant.ios。DeepSeek仍需原有API Key和云端智能配置，按服务实际用量计费。

发布前要求同一源提交的核心、资源、iOS单元和页面检查成功。系统相册选图在Release使用原生PhotosPicker；自动化通过真实ImageIO图片处理/加密测试与DEBUG导入编辑页夹具验证用户代码，不代表已完成用户真机系统相册选图、Face ID和性能验收。未用真实付费API验收引用理解、自定义含义或恶搞表情的语义质量，实际选择仍由模型判断。
