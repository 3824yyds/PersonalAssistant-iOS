## 本次功能与更新方式

个人助理 3.5.1（Build 14）

- 修复伙伴把“[表情包：…]”说明当正文发送、没有真实图片却声称已发图的问题。已知表情说明经过白名单和场景校验后成为实际图片附件，与正文一起加密保存；未知标记、虚构发图回执或无依据的刷新/加载故障猜测会触发至多一次重新生成，持续失败则保留可重试状态。
- “用表情包呀”“图在哪里”“同样的方式抱抱我”等明确请求可再次发送合适图片；普通自动表情继续限制频率，个人开关、温柔语气及认真倾诉的适用限制继续生效。可以只发真实图片，不再生成空白文字气泡。图片语义改为历史附件JSON，避免当成待输出台词照抄；旧聊天原文不被静默改写。
- 聊天顶部只显示头像与名字，去掉“Flash · 文字伙伴”。
- 新增男性伙伴：黑色短发、琥珀色眼睛，黑色高领衫、深灰开衫、小银耳钉和细链。性格按用户最新选择为温柔稳重、善于倾听和安慰；有独立头像和逐张绘制的开心、抱抱、疑惑、无语、得意、晚安六张表情。女生原有资料、名字和聊天保留；两人的名字、私聊、记忆和相处习惯分别保存。
- 伙伴入口改为列表，可以分别进入两人的私聊，也可建群邀请一位或两位（最多12群）。群聊逐条显示发言者头像与名字。普通消息最多让每位成员各回复一次，@选择某一位时只由对应伙伴回复；不启动无限自主互聊。取消或出错后重试只补尚未回复的成员，已经收到的回复保留，不重复添加用户消息。
- 群聊单独保存完整窗口、共享记忆、引用、自定义表情和交接摘要，沿用48,000字符光圈与精简新窗口。人物名字/外貌/基础性格沿用各自资料，私聊原文和私聊记忆不自动带入群里。群里不自动更改个人名字，改名请到对应私聊；每位实际模型回复分别计用量。群名可编辑，列表左滑删除群聊会明确确认，私聊保留。
- 增加可查看、修改、删除及关闭的“相处习惯”。初版从用户明确的长期反馈中积累，例如“以后少用反问、简短一点、先听完再给建议”；按伙伴和聊天空间区分。临时情绪、今天的要求、引用或第三方的话不自动变成人格。稳定性格底色保留，不做API模型权重训练，不从单次笑脸推断心理状态，不增加额外人格训练接口费用。
- 修复时间回答：常见“现在几点了/今天几号/今天星期几”直接按iPhone当前时间和时区生成本地回答，跨日期和夏令时按系统时区处理。其它对话也提供明确的设备当地时间，不根据历史旅行城市猜用户所在地；用户明确问其它地点时才换算。

本版延续Build13的4位PIN和加密封装，新增资料为可选字段。**从Build13更新请用相同Bundle ID及原签名身份覆盖安装，保留现有4位PIN和资料，无需再次卸载。** 旧12位/长密码的Build12及更早资料仍不兼容。未签名iPhone arm64，最低iOS17，iOS26 SDK，Bundle ID cn.local.assistant.ios。

仍需开启云端智能并配置DeepSeek API Key，群聊最多两位各一次实际回复，按服务实际用量计费；按需搜索另计用量。表情使用随包图片或本机自定义图片，不在聊天时实时绘图；自定义照片像素仍保存在本机加密资料中，只传名称与含义。

发布要求同一应用源的核心、资源、iOS单元和页面检查全部成功。服务回归使用URLProtocol模拟协议；新增表情页面检查穿过真实附件校验和加密保存流程，群聊页面夹具验证编排与保存。未使用用户真实付费API连续评估两种性格、群聊接话或长期生成质量，尚未完成用户iPhone真机、Face ID、系统PhotosPicker与性能验收。不承诺所有隐喻、纠正或梗都能正确理解。
