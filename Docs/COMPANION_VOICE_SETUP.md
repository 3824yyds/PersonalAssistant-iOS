# 伙伴语音使用说明 · Build 17

## 安装

使用原签名身份和相同Bundle ID `cn.local.assistant.ios`，覆盖安装到Build13至16。不要卸载；保留四位PIN和现有资料。未签名IPA需要使用原有签名安装方式，不能在Safari里直接安装。

## 首次配置

1. 打开阿里云百炼控制台，使用自己的账号开通北京地域模型服务并检查qwen3-tts-flash当前免费额度与有效期。能否领取以账号显示为准。可开启免费额度用完即停。
2. 在百炼创建北京地域API Key，回到App的伙伴聊天，点右上角「… → 语音回复」。只把密钥填入App的密钥输入框，不要发到聊天里。
3. 选择本聊天的「文字」「语音」或「语音和文字」。分别设置女声、男声及0.8至1.2倍播放速度，点击保存。自动播放默认关闭。
4. 发一条新消息。回复文字先保存，语音生成后可点播放。群聊按发言者使用各自声音，依次播放。语音模式可以点「查看文字」；以前的回复可长按选择「语音播放」。

DeepSeek聊天密钥和百炼语音密钥分开。App不包含共享账号，官方免费演示页面也不能作为聊天语音服务；没有语音账号时可以继续使用文字聊天。免费额度有条件和期限，真实服务的自然度及延迟需在配置后实际体验。

## 常见情况

- **提示未配置**：检查「语音回复」里是否显示密钥已保存。填写自己的百炼北京地域Key。
- **提示额度/鉴权错误**：到百炼检查当前额度、服务开通状态与Key权限，修复后点该条消息的「重试语音」。无需重发用户消息。
- **文字存在但音频未出**：先查看该条消息的错误提示。超出语音长度上限会保留完整文字，不会伪造语音完成。
- **退出页面后停止**：当前设计会在离页、后台、锁定或音频中断时停止生成和播放；回到消息可重新播放或生成。
- **恢复备份后没有录音**：备份保留正文和设置，语音缓存不随资料库备份，可从文字重新生成，可能使用新的语音额度。
- **切换声音/语速**：新声音重新合成会产生新用量；调节播放语速不重新合成。已缓存的旧声音保留到清理缓存。

语音仅发送当前回复的朗读文本；密钥保存在本机钥匙串，音频加密缓存在本机。「清理本机语音缓存」不删除聊天文字。
