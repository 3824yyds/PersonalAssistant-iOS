# iOS 3.5.1 Build 4

- AI 欢迎球改为 88 点蓝白云雾球，内部缓慢流动，响应减少动态效果设置。
- 主页与聊天页使用无整屏背景面的悬浮顶栏，滚动内容限制在顶栏下方；底部导航为独立悬浮层，页面背景延续至安全区域。
- AI 聊天返回键与模型菜单使用分离的玻璃控件。
- 接入 DeepSeek 官方 Search / Fetch 接口，沿用 App 内的 API Key。聊天＋菜单提供联网搜索开关，默认允许模型按需查询，普通对话不强制搜索；每次回答最多两次搜索、两次补充网页抓取。
- 联网回答以结论和必要要点呈现，真实来源编号可点击，回答下方折叠展示来源标题、域名与已知发布日期。搜索失败或无结果不能冒充实时核实；停止回复会取消进行中的请求。来源随加密聊天历史保存。
- 默认模型更新为 deepseek-flash，旧 deepseek-chat / deepseek-reasoner 选择映射至当前模型，自定义模型保留。联网搜索与抓取分别按 5 元／千次成功请求计费，以 DeepSeek 官方文档为准：https://api-docs.deepseek.com/zh-cn/guides/search/ 。
- 润色、摘要、要点、会议纪要、行动清单均在原编辑页显示结果与“采纳 / 取消”。未采纳的结果不写入原文、草稿或资料库；采纳后可撤销；过期结果不能覆盖新修改。
- 新增长列表滚动后的顶部 / 底部背景检查、欢迎球尺寸、返回与模型间距，以及五项技能的页内取消 / 采纳 / 撤销检查。测试中的模拟 AI 结果只存在于 DEBUG 构建。

安装方式见 INSTALL.md。IPA 为未签名 iOS 真机 arm64 构建，需自行签名；模拟器通过不代表已在实体设备验证 Face ID、语音或性能。

搜索与抓取流程使用本地 URLProtocol 模拟接口进行协议验证；没有使用真实付费密钥进行联网端到端实测。
