个人助理 3.5.1（Build 11）

- 伙伴日常聊天改用 DeepSeek Flash；原225步训练成果保留，不再内置或调用旧伙伴模型。
- 人物设定、三档聊天语气、精选对话示例、近期完整角色对话和少量相关旧对话/记忆共同用于生成。支持“嘴再毒一点”“今天别损我”“恢复互损”；当天临时收敛不覆盖平常偏好。
- 明确取名先保存再回执，标题同步；更多自然取名表达可由模型提出确认卡，未确认不宣称已更名。用户自己的称呼与伙伴名字分开保存。
- 明确偏好更正替换冲突记录，撤销能恢复旧偏好；名字循环更改后只有最新回执可以撤销。
- 按需检索不熟悉的网络热梗与当前公开信息，保留真实来源。关闭查询或说“不要联网”时不提供搜索工具；聊天本身仍需要联网。
- 重复回复最多修复一次，仍复读则停止并提供重试；断流、长度截断、余额/密钥/网络失败均不伪装成完整成功回复。停止、返回后保留未回复的用户消息，可重试而不重复添加消息。
- 前台主动接话尊重未回答的问题、晚安/结束话题、编辑、弹窗、草稿和冷却；后台主动与伙伴语音继续停用。

伙伴对话需要开启云端智能并沿用已配置的 DeepSeek API Key，API 按服务实际用量计费。发送范围为当前消息、近期聊天、少量相关旧对话与记忆；不发送整份笔记、账本或资料库。搜索仅使用必要公开关键词，个人资料页面说明了发送范围。

最低 iOS 17，iOS 26 SDK，iPhone arm64，未签名。沿用原签名身份和方式覆盖安装，保持 Bundle ID cn.local.assistant.ios；不要卸载或清空资料。

发布前要求同一源提交的核心及 iOS 定向检查成功。自动化包含纯逻辑、加密备份、模拟 DeepSeek 流/工具、页面操作；不代表已完成用户真机安装或真实付费 API 的连续聊天质量验收。人物语气和理解由生成模型执行，不保证任何热梗都能识别或任何对话都不出错。
