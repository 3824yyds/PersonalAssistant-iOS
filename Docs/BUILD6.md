# 3.5.1 Build 6

本次只实施用户已明确提出的修改；全产品审计发现的额外改进另列建议，待用户同意后实施。

- 备忘录黄色完成按钮保存成功后回到列表；失败保留编辑内容。图片和手绘保留附件数据、预览和编辑能力，正文中隐藏文件名小字。普通文件仍保留文件名入口。
- 聊天输入使用保留输入法 marked-text 的 UIKit 输入组件；笔记正文也保护组词状态，不在拼音候选期间回写文本或 RTF。
- 雾球保持蓝白配色，动画时间倍率由 2.4 提高到 4.0，减弱动态效果设置仍有效。
- 聊天模型选择移除刷新按钮，选中勾显示在模型名称右侧。云端智能设置仍保留模型刷新入口。
- 聊天可按明确要求调用应用工具创建备忘录、实际收入/支出和提醒；只在真实加密保存成功后显示成功卡片。卡片能打开对应编辑页。
- 保存前文回答到备忘录由本机直接完成，无需再调用模型；普通回答也有“保存为备忘录”按钮。
- 金额严格按字符串解析为分，校验账户、币种和现金余额；多账户不能擅自选择，金额或提醒时间缺失时询问补齐。借款和还本不能混记为普通收支。提醒保存后请求系统通知授权。
- 每轮每种类型最多创建一项；重复工具调用返回同一回执。取消、锁定、切换会话、保存后网络中断等路径不能假报成功或重复写入。

云端工具协议使用模拟 HTTP 响应检查；真实 DeepSeek 付费调用需要用户本机的 Key，云端构建环境没有这份密钥。模拟器不能替代真机 Face ID、相机、麦克风、Metal 性能和后台通知送达测试。
