个人助理 3.5.1（Build 12）

- 新增六张按现有蓝发女性头像逐张绘制的透明角色表情包：开心、抱抱、疑惑、无语、得意、晚安。
- 伙伴知道每张表情包的画面、含义和适用场景，通过受限工具选择一张，随成功保存的文字回复展示；不使用任意图片链接，不在回复失败或取消后单独补发。
- 输入区笑脸打开表情包面板，点选即可发送，保留未发送文字草稿。图片、语义编号随聊天一起加密保存，旧窗口可回看；历史对话及精简可以读到表情含义。
- 自动表情包控制频率，不连续刷同一张；认真倾诉时限制调侃类表情，温柔模式不使用无语/得意。前台主动接话仍只用文字。可在她的资料中关闭自动表情包，或直接说“别发表情包”“恢复表情包”。关闭后仍能理解用户发来的本套表情和emoji。
- emoji原样进入上下文，包含组合、肤色及ZWJ序列。增加中文语境指引，区分笑、苦笑、礼貌、反讽等可能含义，不把单个emoji机械等同一种情绪；这不代表新增了任意图片识别功能。
- 修复“大肥鱼 → 名字 → 是叫我‘大肥鱼’对吧 → 对的”确认衔接。短澄清可引用紧邻上一轮用户候选；有用户原话依据的普通确认问句也能形成真正的待确认名字。用户确认后保存、更新标题；模型自行编造的名字不作为依据，无关话题后不会被旧确认误改名。
- 修复精简新窗口偶发沿用旧滚动位置、摘要不可见，以及旧窗口待回复提示残留；历史原文和草稿保留。
- 带反讽的emoji不自动存成长期偏好，装饰emoji不阻止后续偏好更正和撤销。
- 保留Build11的48,000字符完整聊天窗口、用量光圈、精简预览与旧窗口原文、独立人物资料和长期记忆。表情含义也计入窗口用量。

伙伴仍使用DeepSeek Flash，需要开启云端智能并配置原有API Key。聊天和工具选择按实际API用量计费；六张图片随包提供，聊天中不会实时生成图片或为绘图额外调用图像服务。不新增记忆云服务或其它第三方SDK。

最低iOS17，SDK iOS26，iPhone arm64，未签名。沿用原签名身份覆盖安装，Bundle ID cn.local.assistant.ios；不要卸载或清空资料。旧Build11备份兼容新增可选字段。

发布要求同一应用源提交的核心及iOS检查成功。自动化验证协议、保存、图片资源及界面流程；未用真实付费API连续验收表情选择、反讽理解等生成质量，也未完成用户iPhone真机安装和性能验证。不能保证每个emoji、每次反话和每种情绪都理解准确。
