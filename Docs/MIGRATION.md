# Android 3.5.1 → iOS 3.5.1 迁移说明

基线取自用户云盘 `PersonalAssistant-3.5.1-完整源码` 中两个源码包，未使用用户否定的 3.6.0 作为 UI 基线。

| 模块 | iOS 实现 | 平台差异或边界 |
|---|---|---|
| 笔记、账本、提醒、账户、卡包 | 原生 SwiftUI、金额与余额联动 | 原 Android Compose 源码不直接运行于 iOS |
| 资料加密与全量备份 | 相同二进制信封、密码派生和字段数据 | 仅完整备份恢复；API Key、Android聊天历史和设备PIN不在全量资料备份内 |
| 账户/卡面图形 | 复制旧版高质量资源，分离图标图集 | 卡组织为程序绘制标志；不代表银行授权或真实金融服务 |
| 记账/退款/转账/还款 | 原生编辑、校验、联动 | 转账暂限同币种，汇率仅用于查询 |
| 统计与预算 | 多币种分开、分类环图、趋势、日历、预算 | 预算总额与分类额度分别展示，不能重复相加 |
| 贷款 | 网贷/车贷/房贷/公积金/民间等，分期与实际还款 | 金额计算使用Decimal舍入；综合年化IRR是数值估计。暂不提供已登记贷款的未来利率调整编辑器，导入原有利率变更会用于计划计算 |
| 法律风险提示 | 区分民间借贷与持牌金融机构，提示核对合同和证据 | 不是实时法律数据库，不保证自动核实债权方资质或最新政策；不直接判定侵权 |
| 月报 | 确定性账本表格、趋势、建议，可主动请求云端深入分析 | 无历史月份不编造环比。当前余额与所选月份流水明确区分；手动资产/贷款在对应页面核对 |
| 现金流推演 | 31/90天已有未来流水与贷款计划，额外支出情景 | 不虚构工资、不写账；本次预测不自动并入所有订阅/信用卡计划。导入的现金规划字段保留 |
| 订阅 | 添加、编辑、停用、提醒、确认本期付款 | 日期锚定首期；不会假定计划已实际扣款 |
| 资金桶 | 创建、分配、释放、关联支出 | 默认账户币种创建、余额滚存；导入的非滚存配置继续按原规则计算 |
| AA | 成员账本、自定义或平均分摊、实际结算 | 以分为单位处理余数；不代替成员或银行核对。暂未提供历史分摊撤销编辑器 |
| 投资 | 持仓、报价、买卖、分红、成本与盈亏、对应现金流水 | 不自动连接行情或券商；暂不提供撤销历史交易编辑器 |
| 云端 DeepSeek | 固定HTTPS官方API、流式正文、API模型列表与自定义ID | Android旧模型ID可能已失效，应以该API Key实际可用列表为准；不会硬编码宣传中的模型名为有效ID |
| 本机 Qwen | 旧版固定GGUF经llama.cpp/Metal运行，下载/导入校验 | iPhone内存、系统温控决定速度；模拟器只有界面测试桩，不代表本机模型推理 |
| 语音 | Apple Speech zh-CN 实时部分结果、离线优先、简体转换 | 不移植Android Whisper JNI和CPU绑核；离线资源需设备与iOS支持，无“5秒必达”承诺 |
| OCR | 系统Vision中文识别、文稿扫描 | 不使用Android ML Kit；识别后仍由用户核对 |
| 聊天历史与记忆 | 独立加密历史，记忆沿用资料字段 | 聊天历史保留期限按设置处理；安卓历史文件不直接导入 |
| 备忘通知 | iOS用户授权后，隐私化通知正文 | 系统限制待处理通知数量；优先安排最近60项，每次保存/进入应用刷新。重复提醒完成后推进下一期，不保证在用户长时间不打开应用时无限安排 |
| 图标与深色 | 三个旧版图标，原登录背景，纯黑页底 | iOS图标切换可能显示系统确认；登录页按用户早先要求无独立图标 |
| CSV | 微信/支付宝/本产品的UTF-8或GB18030 CSV草稿预览，确认导入，重复键过滤 | 退款/失败/中性交易跳过并明确提示；局部或其他变体需人工核对。导出含公式注入保护 |
| 汇率 | 中行公开折算价，独立公开源回退 | 不改变账目历史币种或金额，不等于实际成交价；不保证中国所有网络可达 |
| 更新 | 重新签名安装IPA覆盖更新 | Android.paupdate、APK和热更新源码不能用于iOS；同一签名与BundleID的数据保留由iOS及签名工具决定 |
| 语义证据搜索 | 本机关键词搜索笔记和账目 | Android BGE嵌入检索暂未移植，原始数据不会因此丢弃 |

没有伪造联网银行余额、模型下载完成、云端回答或真机性能测试。测试中的示例数据只在测试代码和模拟器测试资料库里使用。
