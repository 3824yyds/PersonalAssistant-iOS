# 3.5.1 · Build 9

用户真机反馈已经识别出“你好呀”，但停留在“正在听”，没有进入语音回复。检查发现旧停顿判断会被持续底噪刷新活动时间，导致自动发送一直推迟。此前模拟整句直接跳过了停顿判断，不能作为该路径的验证。

本版新增 VoiceTurnDetector：识别文字实质变化才刷新文本时间；安静停顿可结束一轮，识别文字稳定 2.2 秒后的发送时限不再被环境音量延长。忽略重复、空白和标点修订。新增识别收尾状态和超时兜底，保留最终识别结果，并提供点按云雾球/“发送这句话”的手动发送入口。系统朗读区分准备与实际启动，8秒没有启动回调则显示错误，避免假装正在说。

模拟通话夹具改为只注入识别中间文字和持续高噪声，复用生产停顿计时和发送路径，不再直接注入完整回合。新增独立核心回归与 iOS 识别收尾/取消、中文语音 PCM 输出检查。测试结果按实际运行记录，模拟器产生音频也不等于验证了用户扬声器、音量或蓝牙。

保留此前笔记、模型选择器、语音层移除和全屏语音对话功能。应用标识、钥匙串和资料格式不变，没有数据迁移。

语音对话增加独立口语表达要求：默认1至3个短句、20至80字，先结论、一次一个澄清问题，避免标题和冗长列表；用户明确要求详解时展开，金额、日期和保存回执不被截断。只对 full-screen voice call 的 spoken 请求传递 voiceConversation 标志，普通文字聊天和笔记 AI 不变。该表达风格由提示词引导，不声称已用用户真实 DeepSeek Key 验证所有输出。

用户对新音色服务的最新决定为“先比较试听效果和费用再决定”。目前只准备官方试听与价格对比，尚未接入付费云端 TTS，男/女声及扩展调速界面待服务选定后实现。
