# 债务管理与记账规则（Build 5）

| 操作 | 账户余额 | 待还本金 | 收支统计 |
|---|---:|---:|---|
| 借款到账 2,000 元 | +2,000 | +2,000 | 不计收入 |
| 归还本金 100 元、利息 20 元 | −120 | −100 | 支出 20 |
| 本金 2,000 元，扣费后实到 1,950 元 | +1,950 | +2,000 | 已扣费用支出 50 |
| 仅登记已存在贷款 | 不变 | 增加登记的待还本金 | 不重放收支 |

月度结余是收入减净支出，不是账户余额。借款与还本改变现金，不混入收支。预扣费用记账只还原用户填写的资金，不认定其法律效力。

资产负债页按币种汇总正账户余额、手动资产、账户欠款、手动负债和贷款剩余本金。未来预计利息不作为当前本金负债，信用额度不计资产。已登记贷款或账户欠款无需再添加同一笔手动负债。非信用账户负余额须核对历史账目，不能当作可花资金。

## 合同与计划

- 网贷/消费贷每次实际提款分别登记，未提款授信不产生负债。支持等额本息、等额本金、先息后本、到期一次还本付息和初始本金计息。零息填 0。
- 房贷、公积金贷、车贷默认仅登记，不把直接支付给卖方的资金记进自己的现金账户。房屋/车辆另登记估值，组合贷按两份合同分别管理。
- 私人借贷登记债权方及机构性质，不把受监管金融机构与民间借贷统一套用利率上限。现有法律风险核对保留。
- 浮动利率填写合同重定价日及执行年利率，不自动使用未知 LPR。按日计息、宽限期、不规则分期和实际息费使用“核对还款计划”，逐期填写贷款方合同值。生成的月度计划为参考，不假装是银行精确账单。
- 提前还本独立记录实际本金、利息、违约金。不会推断缩短期限或减少月供；标记计划待核对，旧计划退出现金流预测，提醒仍按原到期日提示核对。新计划本金合计须与已提前归还本金核平。
- 逾期显示过期未完成计划。已经支付的罚息/违约金记费用；展期、减免、协商结果依确认后的合同逐期核对，不自动滚入本金或编造费用。

旧贷款可以填写登记前已还期数，减少待还本金而不重复扣资金。只知道剩余本金时，按剩余本金和剩余期限登记，不推断未知历史。

## 事务与修改

贷款提供编辑、归档、删除、还款历史修改/撤销、提前还本及计划/利率管理。同一期可分多次支付；全部计划本息费付足才标“本期已还”。本金、利息和费用分别入账。

修改还款先移除旧事务再校验新值，避免重复扣款。撤销恢复本金、息费和资金。删除回滚到账和该贷款全部流水及关联退款；若撤回到账会使其他已记账资金不足，则拒绝，可先修正相关记录或归档。归档保留未还负债并暂停提醒。

贷款收付只选人民币、非信用、未归档账户。还款按本金+利息+费用整体校验付款日及后续已记账的每日余额，不足时整笔拒绝。旧版遗留负余额不静默清零，允许撤销或减小错误还款来修复，不允许进一步恶化。

## 自动提醒

登记后自动生成未还期次提醒，默认提前三天 09:00 和到期日 09:00 各一次。可修改提前天数或暂停；部分还款同步余款，还清移除，撤销恢复，修改日期和删除贷款同步处理。点击提醒打开贷款，不能单独打勾冒充已还。

使用 iOS 本地通知。首次保存请求授权，拒绝后仍保留应用内提醒，并提示去系统设置开启。按系统限制滚动安排最近 60 条，解锁及每次保存重排；长期不打开应用、拒绝通知或系统专注模式可能影响展示。锁屏通知隐藏金额与机构名称。
