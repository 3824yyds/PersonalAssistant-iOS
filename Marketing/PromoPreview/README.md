# 个人助理 · 45 秒产品宣传片 · 视觉预览 v1

输出方向：竖屏 1080×1920，45 秒；当前交付为六张关键画面与可离线打开的逐张预览，尚未完成视频转场、配乐或旁白。

| 时间 | 文案 | 画面与后续动效 |
| --- | --- | --- |
| 0–5 秒 | 让日常，更从容一点。 | 账本与助理双机位缓慢错位进入，蓝色环境光扩散，标题分两拍出现。 |
| 5–14 秒 | 灵感来了，随手记下来。 | 全屏笔记，轻推近正文，再点亮黄色完成按钮；功能字幕：全屏书写、拍照识字、AI 整理。 |
| 14–25 秒 | 钱花在哪，一眼看清。 | 先显示流水，再过渡到支出分类统计；展示实际数据结构，演示金额为虚构内容。 |
| 25–35 秒 | 有话，直接说。 | 从实际助理页进入语音界面；蓝色云雾球轻微呼吸。当前预览为静态模拟收听画面，不作为真实麦克风或自然音色证据。 |
| 35–41 秒 | 私人资料，安心收好。 | 原创矢量锁与玻璃卡片动效，显示本地加密、自动锁定、加密备份；同时明确云端 AI 会发送相关内容至模型服务。 |
| 41–45 秒 | 个人助理。记下想法，看清收支，聊聊日常。 | 使用产品已有黄色应用图标与三页面组合收尾。暂不添加 App Store、二维码或下载地址。 |

视觉：冷白留白、低饱和蓝色渐变、克制的玻璃反光，暖黄色产品图标保留品牌辨识。界面画面使用未经内容改写的模拟器截图，在 HTML 中完成尺寸、位置与透视排版。

真实性：本地截图采集使用单独的 `codex/promo-preview` 分支和全新模拟器。`--promo-capture` 仅编译进 DEBUG，准备虚构笔记/收支；语音采用已有 UI 状态夹具，不采集声音、不调用云服务、不表示新音色已经落地。当前 Build 9 安装包未改动，不改用户数据或原有分支。

音乐方向：轻盈的电子氛围、柔和键盘、少量玻璃触点音。视觉确认后再制作音轨与转场。当前没有使用外部商业歌曲、付费配音、素材采购或付费 API。

来源：`assets/app-icon.png` 为仓库现有应用图标。`assets/note.png`、`ledger.png`、`statistics.png`、`assistant.png`、`voice.png` 为实际 iOS 26 模拟器采集；截图旁列的金额与内容均为虚构演示数据。隐私锁图形与宣传版式为本次原创。

重现：安装 Python Playwright，并使用 `/usr/bin/chromium`；运行 `python3 source/render.py`。逐张预览 HTML 已内嵌所有关键画面，可单独下载后离线查看。
