# 个人助理 · 产品操作演示视频

用户已确认视觉方向，并明确要求展示真实操作过程。当前影片以连续的原生应用录屏为素材，不使用静态关键画面作为视频主体。

交付：`个人助理-产品操作演示-45秒.mp4`，1080×1920，45秒，30fps，H.264 + AAC，支持流式播放。界面运行在 iOS 26 模拟器，所有内容与金额均为虚构演示数据。字幕、点击提示、手机边框和原创背景音乐为后期添加。

| 时间 | 实际录制的操作 |
| --- | --- |
| 0–9秒 | 新建笔记，输入「周末小计划」及正文，点击黄色完成，返回列表看到新笔记。 |
| 9–17.5秒 | 新建28元咖啡支出，输入名称并保存，在流水看到这笔支出与更新后的汇总。 |
| 17.5–21.5秒 | 从流水切至分类统计，再切换收支日历。 |
| 21.5–25.5秒 | 打开卡包，展开卡片并查看账户余额与关联流水。 |
| 25.5–32.5秒 | 输入框内打开模型选择器，实际拖动 Flash → Pro → Flash，再收起。 |
| 32.5–35.5秒 | 输入「你好」并发送，显示真实的本机问候回复；没有伪造云端生成过程。 |
| 35.5–41秒 | 进入语音界面，静音、取消静音、结束；影片明确标为「语音界面操作演示」。 |
| 41–45秒 | 打开个人详情并锁定资料库，展示实际解锁页面。 |

语音部分只演示界面和控制操作，没有真实麦克风收音，也没有把配音当作应用回复；音色升级继续搁置。新的付费 TTS、男女声选项与更细调速没有接入。

素材来源：GitHub Actions 运行 `40196944650`，artifact `12600193921`，录制源码提交 `5a3e5e3`，分支 `codex/promo-preview`。`simctl recordVideo` 得到190.955秒连续原始录屏。`PromoDemoTests/testRecordProductWalkthrough` 一项操作流程在142.747秒内通过；这不是全产品测试。事件日志保留实际输入、点击、滑动、保存结果的时间。

剪辑移除测试框架的等待间隔，并适当加速，44段均来自该原始视频。1350帧完整覆盖45秒，未用幻灯片代替操作或伪造页面变化。后期点击圆环是辅助提示，不属于发布版应用。

本次没有更新IPA、版本号、发布分支或用户资料，也没有读取用户密钥或调用付费云服务。

工作区结构：

- `raw/`：原始录屏、录制时钟、操作附件与日志。
- `source/make-assets.py`：生成边框、遮罩及45秒原创背景音乐。
- `source/edit-demo.py`：依据原始操作事件剪辑、渲染字幕、合成并验证MP4。
- `edit-plan.json`、`events.json`：原始时间与成片时间的对应关系。
- `review/`：内部检查用的视频抽帧，不作为产品视频交付。

重现需要 FFmpeg、Python NumPy、Playwright、Chromium 和 Noto Sans CJK 字体。准备原始录屏附件后，依次运行 `python3 source/make-assets.py` 和 `python3 source/edit-demo.py`。
